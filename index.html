    📖 使用说明

    🎡 转盘

    • 添加选项：点底部栏的「⚙️ 设置」打开设置抽屉，输入名称和权重（权重越大越容易被转到），点「添加」。再点「收起 ✕」或灰色区域可关闭抽屉。
    • 多个转盘：顶部标签栏，点「＋」新建，点标签切换，活动标签上的「✕」删除。
    • 重命名：双击标签名或双击选项名，直接改字。
    • 排序：选项右侧的「↑ ↓」调整谁在前谁在后，转盘扇区跟着变。
    • 跳转：点选项旁的「🔗」，可以设置转到这个选项后跳去别的转盘，或跳去硬币/骰子/数字工具页。转中后弹窗里会出现跳转按钮。
    • 扇形贴图：点选项旁的「🖼」，选一张图后进入裁剪编辑器——编辑器里那块扇形就是最终贴在轮盘上的那一块，形状由当前选项数决定（比如 6 个选项就是 60°），转到哪个方向都不变形、不换位置，只是跟着轮盘一起转。拖动平移、双指捏合缩放、旋转/翻转都是在调整构图。确认后贴进那个扇形；再点一次可选「更换」或「清除」。
    • 两种贴图方式（在设置抽屉里切换，全局生效）：整块铺满（默认）——图等比放大到把整块扇形填满、不留底色，超出扇形的部分裁掉，扇形看起来"本身就是这张图"；整张留边——图等比缩小到整张塞进扇形里，四周露出扇区底色。窄扇区（选项很多）时铺满模式只截取图片中间一条竖带，属于正常现象，想看到整张图就切到留边。
    • 主题换肤：在「⚙️ 设置」抽屉里下拉切换 10 种配色，整页按钮、指针、中心点都会跟着变色。「新建主题」可选多色自选或单色渐变（选一个颜色自动生成深浅，选项越多渐变越顺滑）。
    • 盘面外观：「⚙️ 设置 → 盘面外观」里可以换三样东西——盘面字体（雅黑 / 黑体 / 宋体 / 楷体 / 圆体 / 等宽，选中的那项下拉里会直接用该字体预览）、文字颜色（白字深描边、黑字白描边、跟随主题色、或自己挑一个颜色——浅色自动配黑描边、深色自动配白描边）、指针样式（细针小箭头 / 大箭头 / 圆点粗针 / 盘外顶部标记）。只影响扇形上的文字和指针，界面按钮不受影响，免得排版错乱。
    • 音效：转动、抛硬币、摇骰子、切页面都有声音，详见下面「🔊 音效」一节。
    • 淘汰制：勾选「转中后自动移除该选项」，适合多人轮流淘汰。
    • 分享：「生成分享码」会把当前转盘和它跳转链上的所有转盘打包成一串码，发给朋友；对方在「导入转盘」里粘贴即可得到一模一样的转盘——配色、扇形贴图、硬币正反面、自定义音效、音效风格和音量都一起带过去。上面两个勾选框可以决定要不要连图片、连音效，纯文字分享就把两个都取消。带图片音频的码会比较长，选择「存成文件」发 .txt 比复制粘贴更稳。

    🪙 硬币

    • 点「抛！」，硬币翻转后停在正面或反面，各 50%。
    • 默认是一元硬币样式（正面 1元、背面菊花）；点「正面图片 / 反面图片」可以换成自己的图，会先进入裁剪编辑器。

    🎲 骰子

    • 选 1~6 个骰子，点「摇！」，显示每个骰子的点数，多个时显示总和。

    🔢 随机数字

    • 输入最小值和最大值（整数，含两端），点「生成！」。
    • 「生成个数」可一次出 1~100 个；关闭「允许重复」则一批之内数字互不重复。

    🔊 音效

    • 内置音效（由浏览器现场合成，不联网、不占存储）：
      · 转盘旋转时是机械跳齿的「哒哒」声，转得越快越密、快停时一下一下变慢；
      · 转出结果是一段清脆的「冰晶三连音」；
      · 抛硬币有起手的金属「叮」、空中翻飞的连串轻响、落桌的「锵」；
      · 丢骰子是摇盅的沙沙撞击加落定的「咔哒」；
      · 随机数字出一声清铃；
      · 切换页面和转盘有很轻的「嗒」。
    • 总开关：「⚙️ 设置 → 音效」里的勾选框，取消后所有声音彻底静音，设置会记住。
    • 四种音效风格：同一套动作可以换不同音色，在「⚙️ 设置 → 音效风格」里选，选完会自动试听：
      · 冰晶（默认）——清亮、玻璃钟琴感；
      · 木质（木琴）——低沉、敲木头的闷响，跳齿像老式转盘；
      · 电子 8-bit——方波、游戏机提示音那种；
      · 轻柔（马林巴）——圆润小声，余音长，适合安静场合。
    • 换成自己的音频：「⚙️ 设置 → 自定义音效」里，五个动作（转出结果 / 转盘跳齿 / 抛硬币 / 丢骰子 / 点击切换）可以分别导入本地文件替换。每行有「🎵 导入」「试听」「✕ 恢复默认」。
    • 支持格式：MP3 最稳（推荐）；WAV、M4A/AAC 也可以；OGG 在 Chrome 上能用但 iPhone 的 Safari 不行；MP4 不建议——它是视频容器，浏览器把它当音频播放经常失败，请先转成 MP3。
    • 文件大小：单个文件请在 1MB 以内（最多 1.5MB）。因为音频要存在浏览器本地，而总空间只有 5MB 左右，还要和你导入的扇形贴图共用。超了会拒绝并提示，存储满了会自动回滚，不会把你的设置搞坏。建议掐一段 1~3 秒的高潮部分。
    • 只在本机生效：自定义音频保存在你这台设备上。生成分享码时勾上「连自定义音效一起分享」，音频也会被打包进去带给对方；不勾就只分享转盘本身。
    • 音量与响度配平：「⚙️ 设置 → 音效」里有两层滑杆。总音量调整体，拖到 0 就是全部静音；下面的各音效单独音量一共 6 根（转出结果 / 转盘跳齿 / 抛硬币 / 丢骰子 / 随机数字 / 点击切换），每根只管自己那一个，旁边有「▶」可以立刻试听，松手也会自动试听一次。哪根觉得偏大就往左拉、偏小往右拉，互不影响；下面的「全部恢复 100%」一键归位。
    • 配平是怎么算的：各音效的相对响度是按实际波形量出来的峰值配平过——点击、跳齿这类高频轻音压在 -20dBFS 左右（听得见但不吵），抛硬币、丢骰子在 -13dBFS，出结果最大、约 -11dBFS。所以不会出现「点一下吓一跳、出结果反而听不清」。滑杆是在这个基础上再乘一层。
    • 导入的音频会自动对齐：给某个动作换了自定义音频后，程序会先量它本身的峰值，再自动抬/压到和内置音效同一量级（约 -10dBFS），所以换一首很响的流行歌也不会炸出来；那个动作的单独滑杆同样管用。

    🔍 界面大小（手机上觉得小就调这里）

    • 「⚙️ 设置」抽屉最上面有界面大小：标准 / 大 / 特大。按钮、输入框、选项行、底部导航会一起放大，触控区域更大、不容易点错，设一次就记住。
    • 触屏设备（手机、平板）默认就是「大」；手机上还嫌小就选特大。选项列表在手机上会自动拆成两行——第一行名字和权重，第二行操作按钮靠右，按钮做大也不会把名字挤没。
    • 另外现在支持双指放大整页（以前关掉了），临时看不清可以直接捏合放大。

    📱 浏览器要求（重要）

    • 不追求安装怎么办：如果你只是临时用一下，不需要在桌面设置快捷方式、也不需要离线使用，那么用任何普通浏览器打开链接就行——转盘、硬币、骰子、数字这些功能在什么浏览器里都能正常用。
    • 安卓手机：请用 Chrome 或 Edge 打开，安装到桌面和离线功能都完整支持。
    • iPhone：必须用 Safari（底部分享按钮 → 添加到主屏幕），其他浏览器都装不了。
    • 注意：微信/QQ 里直接点开的内置浏览器有时会拦截或排版异常，建议把链接复制出来，用手机自带的浏览器打开。
    • 电脑：Chrome / Edge 直接用，点地址栏右侧的安装图标可装成桌面应用。

    💾 数据与离线

    • 所有转盘、主题、图片、自定义音频都自动保存在这台设备的浏览器里，换设备不会同步。
    • 安装到手机桌面后（浏览器菜单里的「添加到主屏幕」，或页面里的安装按钮），断网也能正常使用。
    • 分享码可以连图片和音频一起带上（默认带），跳转链接会自动映射到对方设备上的新转盘；带媒体的码会压缩，但码本身会明显变长。
    • 安卓手机还可以用安装包（APK）装成独立 APP，图标在桌面上、全屏无地址栏；APP 打开的就是网页版本身，所以网页更新了什么，APP 里就有最新的，不用重新安装。
    • 现在是最新版吗：网页每次打开都会先联网取最新页面（断网才用本地缓存），所以正常情况不会落后。如果 APK 或桌面图标里看起来还是旧界面，用「⚙️ 设置 → 版本与更新 → ⟳ 立即更新」清掉本地缓存重载即可；你的转盘、贴图、音效设置都不会丢。
